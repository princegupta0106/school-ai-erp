# School Portal – mobile (Expo)
Done so far: Home dashboard, Users, Payroll & Leave, Communication, Attendance, Academics, Fees, Homework, Visitors, Queries, Admissions, Documents, Audit logs, Backup, School, Student profile. Transport, Inventory and Timetable added. Remaining: Examinations, Admissions pipeline (see MOBILE-PARTS-PLAN.md). Run `run-mobile.bat` (or `./run-mobile.sh`), scan the QR with Expo Go.
The app calls the hosted API at https://school-ai-erp.onrender.com (change it in `mobile/.env` -> EXPO_PUBLIC_API_URL, then restart Expo).
